The dynamic group type object

Type: String

Encodes the type of a dynamic group.

Allowed values:

Value Description
"accent" Used for dynamics that are temporary accents on a single beat, such as sfz (sforzando).
"gradual" Used for hairpins (crescendo, diminuendo).
"immediate" Used for standard dynamics such as f and p. The dynamic value is an absolute value (not a relative one). This is the most common type of dynamic.
"relative" Used for dynamics whose value is meant to be interpreted relatively, like più p ("quieter").
