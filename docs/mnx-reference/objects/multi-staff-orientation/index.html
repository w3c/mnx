The multi-staff orientation object

Type: String

Represents a symbol's vertical orientation, with support for multi-staff music via the "between" value. See also orientation, which doesn't support "between".

Allowed values:

Value Description
"above"
"auto" Consuming applications are free to use their own algorithms to determine orientation.
"below"
"between" Between multiple staves of music. For example: between the two staves in a grand staff.
